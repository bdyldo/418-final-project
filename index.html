MPMC Ring Buffer in a Trading-System Market Data Pipeline

Evaluating queue designs under realistic producer-consumer workloads with throughput, latency, contention, and scalability analysis.

Project Summary

We propose to study bounded producer-consumer queue designs in the context of a modern trading-system workload. Our core data structure is a lock-free bounded MPMC ring buffer using per-slot sequence numbers, compared against mutex-based and lock-based baselines.

Rather than evaluating the queue in isolation, we embed it into a simulated market data ingestion pipeline: 

[Feed Handler Threads] → [Queue] → [Processing Threads]

Motivation

In trading infrastructure, market data feed handlers must process bursts of incoming updates with extremely low latency. Queue behavior under contention directly impacts end-to-end throughput, tail latency, and drop behavior.

What We Will Build

  • Mutex-based queue baseline
  • SPSC ring buffer baseline
  • MPMC queue with locks
  • Lock-free bounded MPMC ring buffer
  • Trading-style market data pipeline benchmark harness

Application Workload

We will simulate producers generating:

  • Uniform-rate message streams
  • Poisson arrivals
  • Bursty spike-driven workloads

Consumers will process messages by updating in-memory state or computing lightweight statistics.

Technical Challenges

  • Memory ordering and publication correctness
  • Atomic fetch_add contention
  • False sharing on shared metadata
  • Queue wraparound and bounded-capacity pressure
  • Tail latency under bursty producer load

Evaluation Plan

  • Throughput (ops/sec)
  • Latency (avg, p95, p99)
  • Scalability vs thread count
  • Performance under low/high contention
  • Effect of queue size and task size

Expected Outcome

We expect lock-free designs to outperform lock-based baselines under moderate concurrency, but to show degradation under heavy atomic contention and bursty workloads. The project will characterize when lock-free helps, when it stops helping, and why.
